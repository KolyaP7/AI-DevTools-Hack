# MCP Server Example

Пример MCP сервера, демонстрирующий стандарт разработки согласно инструкциям.

## 🚀 Возможности

- **example_tool** - Пример инструмента с полным набором практик:
  - Логирование через Context
  - Прогресс-отчеты для длительных операций
  - OpenTelemetry трейсинг
  - Обработка ошибок через McpError

## 📋 Требования

- Python 3.12+
- Зависимости из `pyproject.toml`

## 🔧 Переменные окружения

### Обязательные переменные

Нет обязательных переменных для базовой работы.

### Необязательные переменные

- `PORT` - Порт сервера (по умолчанию: 8000)
- `HOST` - Хост для прослушивания (по умолчанию: 0.0.0.0)
- `MCP_SERVER_NAME` - Имя MCP сервера (по умолчанию: mcp-server)
- `OTEL_ENDPOINT` - OpenTelemetry endpoint для экспорта трейсов
- `OTEL_SERVICE_NAME` - Имя сервиса для OpenTelemetry (по умолчанию: mcp-server)
- `LOG_LEVEL` - Уровень логирования (по умолчанию: INFO)
- `API_KEY` - API ключ для доступа к сервису (если требуется)

## 🚀 Локальный запуск

1. Установите зависимости:
```bash
uv sync
# или
pip install -e .
```

2. Создайте файл `.env`:
```bash
cp .env.example .env
# Отредактируйте .env файл при необходимости
```

3. Запустите сервер:

**Для разработки с использованием fastmcp dev (рекомендуется):**
```bash
# Запуск через fastmcp dev (использует stdio транспорт)
fastmcp dev mcp/server.py
```

**Для прямого запуска с HTTP транспортом:**
```bash
# Способ 1: Используя скрипт запуска из корня проекта
python run_server.py --http
# или
./run_server.py --http

# Способ 2: Как модуль Python из корня проекта
python -m mcp.server --http

# Способ 3: Прямой запуск из директории mcp/
cd mcp
python server.py --http

# Способ 4: С использованием uv
uv run python run_server.py --http

# Способ 5: Через переменную окружения
MCP_TRANSPORT=http python run_server.py
```

## 📖 Использование инструментов

### example_tool

Пример инструмента с полным набором практик разработки.

**Параметры:**
- `query` (str) - Поисковый запрос для обработки
- `limit` (int, опционально) - Максимальное количество результатов (по умолчанию: 10)

**Возвращает:** Результаты обработки запроса в структурированном формате

**Пример использования:**
```python
result = await example_tool(query="test query", limit=5)
```
